# pages/

Published documentation — rendered into the site, read by users of Torve.

Derived, not a source (D-A.1a): a page links to decisions in `rfcs/` and
never restates them, or the site ends up hosting a stale copy of something
that lives under a number. Same principle as the generated `INDEX.md`, one
level up.

Empty until the first user-facing page exists; do not park anything else here.
